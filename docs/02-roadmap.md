# DPRC Platform Development Roadmap

---

# Purpose

This roadmap outlines the planned evolution of the DPRC Platform. It serves as a high-level guide for development while remaining flexible as new requirements emerge.

The roadmap is organized into milestones rather than fixed deadlines.

---

# Version 0.1 — Foundation

## Goal

Build a solid technical foundation for the platform.

### Features

- Project setup
- Professional folder structure
- Application layout
- Navigation
- Footer
- Responsive design
- Theme system
- Home page
- About page
- Research page
- Error page

---

# Version 0.2 — User System

## Goal

Introduce user authentication and account management.

### Features

- User registration
- Login & logout
- JWT authentication
- User profiles
- Role management
- Protected routes

---
