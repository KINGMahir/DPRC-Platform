# Project System

## Overview

The Project System is the central workspace of the DPRC Platform.

Every engineering activity, research initiative, innovation, product, startup, competition, thesis, laboratory work, publication and collaboration is represented as a project.

The Project System connects users, organizations, publications, files, discussions, datasets, tasks, equipment and AI into a unified workspace.

---

# Vision

A project is not simply a page.

A project is a living engineering workspace.

It continuously evolves from an idea to research, development, testing, publication, deployment and long-term maintenance.

---

# Core Philosophy

Everything meaningful happens inside a project.

Projects become the primary collaboration unit of the platform.

---

# Project Identity

Every project has three identifiers.

## Internal ID

Example:

```text
PJT-000001
```

Used internally.

---

## Public Slug

Example:

```text
smart-grid-monitoring
```

URL:

```text
/project/smart-grid-monitoring
```

---

## Official Project Code

Example:

```text
DPRC-PRJ-2026-000001
```

Used in publications, reports, certificates and documentation.
